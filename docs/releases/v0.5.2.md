A patch release for scenario effects after a jump.

## Fixed
- Jumping to a line no longer replays one-shot scenario effects from the start. A jump restores every effect that is still playing at the target, and an effect the scenario never stops, such as the tree flash in wl_3rd_finale_01, counted as playing, so it flashed again on every jump. A restored effect is now run on unseen for as long as its first run takes (at most 10 s) before it shows: a one-shot has played out, and a looping effect such as rain or snow is already under way.
