A minor release: every load can move to a fallback host when its host fails, and a scenario can be downloaded in full before it plays.

## Added
- `AssetResolver.fallback?(url)`: the same file on another host. Every load uses it when the host fails with a network error, a timeout, a 5xx or a body cut short, never after a 4xx: JSON, mocs and textures, voices, SEs and BGM, backgrounds, movies, effects and their textures, UI sprites, fonts and the Cubism Core script. Element loads check the failure with a `HEAD` request. A failed host goes behind its fallback for 60 s, and a file served from the fallback stays there. (#21)
- `preload` option and `load(…, { preload })`: download every file the scenario uses before it plays, with the bar showing files and MB. Files go into the browser's HTTP cache instead of memory, so a 170 MB episode adds about 25 MB of short-lived garbage. Files that fail on every host get a Retry and a Play anyway button, and the next `load()`, `stop()` or `destroy()` cancels the downloads. (#21)
- `preload` and `preloaded` events, and the `preloading`, `preloadFailed`, `retry` and `continue` labels. (#21)
- Web app: `?preload` turns preloading on. (#21)

## Changed
- Voice and SE fetches time out after 8 s per attempt (was 15 s), so a stalled host gives way to its fallback while the line still waits for its voice. A BGM or SE element that can't play within 12 s moves to the fallback host, and a movie that can't start within 20 s does the same, or is skipped when there is no fallback. (#21)
- Bodies shorter than their `Content-Length` count as failures and are retried. (#21)
