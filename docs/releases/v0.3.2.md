A patch release that matches the game's story pacing, measured against a native trace of JP 7.0.0 playing event_145_07 in auto mode. The whole episode now ends within 0.5 s of the game, against 23 s before. (#17)

## Fixed
- Auto mode waits on motions as the game does: a voiced line pages on only once no layout is running and every shown character's body motion has ended, then 0.5 s more. Short voiced lines over a 2.6 s motion held 1.5–2 s too briefly.
- A motion that starts while another is playing is no longer dropped. The Live2D library turned it away at normal priority, so talk motions and ChangeMotions that overlapped one were lost; the same motion now restarts with the game's 0.125 s blend.
- Entrances finish with their 0.1 s fade (about 0.134 s), not after a fixed 0.2 s.
- Snippets go out one per frame and each action starts the frame after it is dispatched, as in the game; this keeps hides at 0.2 s and spaces lines 2 frames apart.
- Typing waits for the window's 0.2 s fade-in each time it reopens, not only on the first line.
- A voice end is noticed a frame later, as the game's playback manager does.
- Playback waits up to 5 s for the first line's voice, which could start 0.4 s late.
- A character's first entrance no longer stalls up to 0.8 s: each model is drawn once off-screen as it loads, so texture upload and shader compiles don't land on its fade.
