A patch release for the opening poses of scenarios that start with characters on stage.

## Fixed
- Characters placed by a scenario's first layout (area talks, and any scenario that opens with characters on stage) now start in their opening motion. The model's motion list was built from the layout snippets and talk lines only, so a motion used only in the first layout was missing and the character stood in its default pose until a later line gave it another motion. Preloading now fetches those motions too.
