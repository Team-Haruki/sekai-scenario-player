The first tagged release: the embeddable player, now with everything the Haruki Toolbox story player needs. Hosts that copied the engine can switch to this package.

## Added
- Load scenarios into a framework-free player: `createPlayer` / `PjskPlayer`, an asset resolver, events, a preview site and a local asset server. (11337f2)
- Give every asset candidate URLs, tried in order, and pass per-episode context to the resolver; custom model and motion rules, and a physics override. (#5)
- Mute, turn voices off, go fullscreen (with a sideways overlay on iPhone), pick the menu buttons, switch fonts for Chinese and Korean text, change labels at runtime and drive the overlay from the host. (#6)
- Show loading progress: a bar with the count of characters playback waits for, and a `loading` event. (#7)

## Changed
- Start playback once the characters on stage for the first lines are loaded; the rest load while the episode plays. (#7)
- The default menu offers fullscreen and mute instead of the game's bookmark, consecutive and skip buttons; `GAME_MENU` restores the game's panel. (#6)

## Fixed
- Play voices in auto mode before the first tap, when the browser allows audio but keeps Web Audio suspended. (#6)
- Never stay on the loading screen: requests time out and retry, a stalled character is skipped, and an appearance waits at most 12 seconds. (#7)
- Retry a background that failed to load, and keep failed voice candidates from cutting a line short. (#5)
- Keep the player on screen on phones, add a fullscreen button and fit the settings dialog on the preview site. (#3)

## Upgrade notes
- Resolver members for BGM, SE, voice and backgrounds now return `AssetUrls` (a URL, a list or `null`), and every per-episode member gets a `ctx` argument. Resolvers that return a single URL keep working.
- `menu: true` now shows `DEFAULT_MENU`; pass `GAME_MENU` for the game's buttons.
- Node.js 22.18 or later runs the asset server.
