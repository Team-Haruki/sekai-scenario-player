A minor release: hosts can hand in files they downloaded themselves and drive the loading bar, the built-in bar says more, and the web app gains a player-only view.

## Added
- `provideFiles(files)` / `clearFiles(urls?)` and `load(…, { files })`: hand the player `Blob`s keyed by the URL the resolver gives for each, and it reads them instead of downloading. Every file a scenario loads is looked up, including a model's moc, textures and physics by their URL relative to the model3. (#19)
- `setProgress({ loaded, total, label?, bytes? })`: drive the loading bar while the host downloads; `null` or the next `load()` gives it back. (#19)
- The `loading` event carries `files: { started, done, bytes, provided }`, and the bar text shows the costumes, files loaded of those asked for, and the MB so far; new `files` label. (#19)
- Web app: `?view=player` shows the player alone, filling the window, and `?src=<url>` plays a scenario JSON from a URL. (#18)

## Changed
- A model's moc, textures and physics load through the player's own fetch, with its retries: 60 s per attempt for the moc and textures, 15 s for JSON. Textures start as soon as the model3 names them, alongside the Live2D runtime, and are freed with their model. (#19)
